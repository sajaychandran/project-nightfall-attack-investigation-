# GitHub setup

From the project directory:

```powershell
git init
git add .
git commit -m "Build Project Nightfall investigation lab`n`nCo-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>"
git branch -M main
git remote add origin https://github.com/YOUR-USER/project-nightfall-attack-investigation.git
git push -u origin main
```

Create the empty repository on GitHub first. Review `.gitignore` and `git status` before committing. Never add credentials, `.env`, or real incident data.
