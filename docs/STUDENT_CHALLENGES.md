# Student challenges

1. **Evidence or assumption?** Label statements as observed, hypothesised, or unsupported.
2. **Find the mapping.** Choose one technique and cite evidence plus a limitation.
3. **Find missing evidence.** Select the log source that would best test a hypothesis.
4. **Build the map.** Export a layer with annotations and status.
5. **Defend your conclusion.** State what is known, suspected, unresolved, and next.

Feedback is built into the workflow: the app requires evidence IDs and rationale, displays limitations, and prevents unsupported status transitions.
