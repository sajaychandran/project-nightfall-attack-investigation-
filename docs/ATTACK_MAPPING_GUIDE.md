# ATT&CK mapping guide

Map behaviour, not labels. Start with the exact event and ask whether it demonstrates a technique, merely suggests one, or has a benign explanation. `proposed`, `further_investigation`, `supported`, and `rejected` are analyst workflow states, not MITRE classifications. A supported mapping requires a rationale and should name the evidence IDs.

The local catalogue targets Enterprise ATT&CK v15 and is intentionally limited to techniques relevant to Project Nightfall. Check the official v15 release before adding a technique.
